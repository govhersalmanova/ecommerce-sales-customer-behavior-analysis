# E-commerce Sales & Customer Behavior Analysis

## Project Overview
This project analyzes a synthetic e-commerce dataset containing **3,000 orders** from Azerbaijan in 2025. The goal is to identify sales trends, customer behavior patterns, delivery issues, product return risks, and business growth opportunities.

## Business Questions
- How did revenue change throughout the year?
- Which categories and cities generated the most revenue?
- Which categories had the highest return rates?
- How did delivery time affect customer ratings?
- Which customers generated the most value?

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- SQL
- Jupyter Notebook

## Key KPIs
- Total Net Revenue: **407,175.17 AZN**
- Total Profit: **133,513.24 AZN**
- Average Order Value: **135.73 AZN**
- Overall Return Rate: **7.67%**
- Average Rating: **4.27/5**

## Main Insights
1. **Electronics** generated the highest net revenue.
2. **Baku** was the strongest city by revenue.
3. **Fashion** had the highest return rate.
4. Longer delivery times were linked to lower ratings.
5. Card payments were the most common payment method.

## Business Recommendations
- Prioritize high-performing categories and cities.
- Investigate high-return categories and improve product descriptions.
- Reduce delivery delays, especially orders taking six or more days.
- Build retention campaigns for repeat customers.
- Track revenue, profit, returns, and customer ratings monthly.
